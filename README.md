## `cat security_lab.md`

Minha abordagem é **Secure by Design**: segurança não entra apenas no final do desenvolvimento.

```text
[✓] consultas parametrizadas contra SQL Injection
[✓] validação e sanitização de entradas
[✓] autenticação e controle de acesso
[✓] princípio do menor privilégio
[✓] registro e análise de logs
[✓] documentação de riscos e mitigações
```

Estudos atuais incluem **SQL Injection, XSS, autenticação fraca, IDOR, OWASP Top 10, segurança de APIs e proteção de dados**.
